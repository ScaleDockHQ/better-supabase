Nine blocks (agent-checkout, appraisals, dam, lims, maintenance, rfqs, risks, tills and warehouse) page, facet and count through one shared implementation. Each list entity declares `sorts`, `facets`, `filters` and `search` in its manifest, and the SQL list function serves the page, the facet values and the count, so the three always describe the same rows (ADR 0749). `better-supabase/blocks` exports `EntityListSurface`, `EntityList`, `FacetOptions` and `CountOptions`, and `EntitySurface` gains `filters`. The `sso` block keeps its SCIM `startIndex` and `count` paging, because it is not an entity list. Each block page method now takes `PageOptions`, the page options interfaces and the `total` and `totalCap` options are removed, and `dam` and `maintenance` gain `getRight`, `getPlan` and `getCalibration` with the SQL functions `get_usage_right`, `get_maintenance_plan` and `get_calibration`. Apply the generated migration to adopt the new list functions.

| Before                                                                                                                                                  | After                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `RiskPageOptions`, `CheckoutSessionPageOptions`, `AgentMandatePageOptions`, `AppraisalPageOptions`, `DamUsageRightPageOptions`, `LimsSamplePageOptions` | `PageOptions` from `better-supabase/blocks`                                                                |
| `MaintenancePlanPageOptions`, `MaintenanceCalibrationPageOptions`, `RfqPageOptions`, `TillSessionPageOptions`, `PickListPageOptions`                    | `PageOptions` from `better-supabase/blocks`                                                                |
| `risks.page({ status: "open" })`, one value per filter                                                                                                  | `risks.page({ filters: { status: ["open", "assessed"] } })`, a list per filter                             |
| `risks.page({ search: "supplier" })`                                                                                                                    | `risks.page({ q: "supplier" })`                                                                            |
| Newest-first order only                                                                                                                                 | `sort: { by: "nextReviewOn", direction: "asc" }`, one of the entity's declared `sorts`                     |
| `page({ total: true, totalCap })` returned `total` and `totalCapped`                                                                                    | `<x>Count(options)` returns `{ value, exact }`                                                             |
| No facet counts                                                                                                                                         | `risks.facets()` and `<x>Facets()` return the values of each declared facet with `{ value, exact }` counts |
| `sessionPage`, `mandatePage`, `appraisalPage`, `rightPage`, `samplePage`, `planPage`, `calibrationPage`, `rfqPage`, `pickListPage` with scalar filters  | The same names, with list filters, plus `sessionFacets`, `sessionCount` and the matching pair per list     |
| A detail page reads a usage right, a maintenance plan or a calibration from the list                                                                    | `getRight`, `getPlan` and `getCalibration`                                                                 |
| Unknown sort, filter or facet reached the database                                                                                                      | An `invalid_input` `DbError` with `field: "kind"` before any call                                          |
