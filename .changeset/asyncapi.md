New `better-supabase/asyncapi` subpath: `createAsyncApi` and `asyncapiFormat` render AsyncAPI 3.0 and 3.1 from the same API model as OpenAPI. The document describes Realtime table changes and broadcast topics on the websocket server, CloudEvents with a header trait (`CLOUD_EVENT_TRAIT`) and a `dataschema`, outgoing webhooks, and the events that resource actions emit.
