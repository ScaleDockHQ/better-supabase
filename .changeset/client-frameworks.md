Add `better-supabase/vue`, `better-supabase/solid` and `better-supabase/svelte`. Each binds the browser client to its framework with the same features as `better-supabase/react`: the auth state, typed repositories and query factories, live queries, live counts, broadcast topics, presence, server actions and the server-verified session. With a `queryClient`, each clears better-supabase queries when the user changes. The Nuxt module now auto-imports the composables `better-supabase/vue` exports.
