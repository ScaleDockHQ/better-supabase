Every CLI command that writes files now goes through one file plan. Each file gets one line: `Created`, `Updated`, `Unchanged`, `Skipped` (with the reason) or `Removed`, and `Would create` or `Would update` under `--dry-run`. These lines replace `Wrote`, `Kept` and `Would write`, so update any script that matched the old words. Under `--json`, `data.files` lists every file with its outcome; `seed`, `env` and `openapi emit` no longer return `data.wrote`, and `gen` no longer returns `data.removed`.

Every writing command takes `--dry-run`, which prints a diff and writes nothing, and `--check`, which exits 1 on drift. `gen`, `introspect`, `scaffold`, `seed`, `env`, `keys`, `skills`, `spec`, `codemod`, `apply`, `adopt` and `openapi emit` gain the flags they were missing. A command writes its files together, so a failed run leaves none half written. It refuses paths outside the project root and never prints the contents of `.env.local` or the signing keys in a diff.

A generated file without the `Generated by better-supabase` header was written by hand. `gen` used to overwrite it; now every command skips it and exits 1 with the new `file_conflict` error code. Pass `--force` to overwrite it.
