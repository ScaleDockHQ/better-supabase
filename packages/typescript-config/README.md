# @better-supabase/typescript-config

Shared `tsconfig` presets for the monorepo. Private, never published.

- `base.json`: strict settings for every workspace.
- `library.json`: adds `declaration` and `isolatedDeclarations` for published code.
- `react-library.json`: library preset with JSX and DOM libs.
- `next.json`: Next.js apps (bundler resolution).
