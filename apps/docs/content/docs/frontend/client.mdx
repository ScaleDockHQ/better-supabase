---
title: Browser client
description: Repositories in the browser that follow the session.
---

```ts title="src/lib/supabase.browser.ts"
import { createBrowser } from "better-supabase/client";
import { sb } from "./supabase";

export const browser = createBrowser(sb, {
  env: {
    url: import.meta.env.VITE_SUPABASE_URL,
    publishableKey: import.meta.env.VITE_SUPABASE_PUBLISHABLE_KEY,
  },
});

const customers = await browser.db.customers
  .findMany({ select: ["id", "name"] })
  .orThrow();
```

- `browser.db` carries the current session's actor and claims, so plugins
  like [`actor`](/docs/plugins/actor) and [`tenant`](/docs/plugins/tenant)
  behave as they do on the server. It is rebuilt when the user changes.
- `browser.queries` holds [TanStack Query options](/docs/frontend/query).
- `browser.auth` is a small store (`current()`, `subscribe()`) for UI state:
  `loading`, `signed-out`, or `signed-in` with the user and decoded claims.
  The claims are for display; RLS is what enforces access.
- `browser.supabase` is the supabase-js client, for auth flows, storage and
  anything else.

## Storage

| `storage`           | Use it for                                                                                    |
| ------------------- | --------------------------------------------------------------------------------------------- |
| `cookies` (default) | apps with a server (Next.js, SvelteKit, …): the session is shared via `@supabase/ssr` cookies |
| `local`             | SPAs without a server: the session lives in localStorage                                      |

For React Native and Expo, pass your own client:

```ts
import AsyncStorage from "@react-native-async-storage/async-storage";

const browser = createBrowser(sb, {
  client: createClient(url, publishableKey, {
    auth: {
      storage: AsyncStorage,
      persistSession: true,
      detectSessionInUrl: false,
    },
  }),
});
```

The publishable key and URL are validated like on the server: a secret key
or a legacy JWT key is rejected before any request is made.
