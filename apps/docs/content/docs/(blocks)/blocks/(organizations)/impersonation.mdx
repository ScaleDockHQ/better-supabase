---
title: Impersonation
description: Support sessions a second approver authorizes, with a narrowed token and an audit entry.
---

`impersonation` runs a support session: an operator starts one for a member,
a second approver authorizes it, and the session carries a narrowed token that
the access functions honour. The
[impersonation guide](/docs/auth/impersonation) covers the approval, the
scope of the token and the audit trail.
