title: Support sessions
description: Let platform staff view the app as a user, time-limited, read-only by default, approved by a second admin and audited.
---

`impersonation` lets platform staff view the app as a user. A support
session is time-limited and read-only by default, needs `is_platform()` and a
second admin's approval, and lands in the audit log. Your access token hook
builds the target user's claims, and security definer writes refuse a
read-only session.

```bash
better-supabase add impersonation
```

The `better-supabase/blocks/impersonation` client calls the same functions from TypeScript:

```ts
import { createImpersonation } from "better-supabase/blocks/impersonation";

const impersonation = createImpersonation({ transport });
await impersonation
  .request({ target: userId, reason: "Ticket 4812" })
  .orThrow();
await impersonation.approve(requestId).orThrow();
const sessions = await impersonation.list({ active: true }).orThrow();
await impersonation.end(sessionId).orThrow();
```

`start` opens a session without a request, as the admin who is calling. The [Impersonation guide](/docs/auth/impersonation) has the setup and the full reference.

## Paging support sessions

`sessionPage` pages the sessions of every tenant by keyset (ADR 1077) and `getSession(id)` returns one, or a `not_found` error. The list is platform-wide, so it takes no organization, and the SQL function checks the platform admin role. `list` stays as a deprecated alias until 0.70. Filters are `adminId`, `targetUserId`, `tenant` and `active` (`["true"]` keeps the sessions that have not ended or expired). The list has no text search.

```ts
const sessions = await impersonation
  .sessionPage({ filters: { active: ["true"] }, sort: { by: "startedAt" } })
  .orThrow();
```

A cursor belongs to the sort it came from, so start again from the first page when `sort` changes. A sort, filter, facet or text the entity does not declare returns an `invalid_input` error. [Block lists](/docs/extending/block-lists) describes the options every block list shares.
