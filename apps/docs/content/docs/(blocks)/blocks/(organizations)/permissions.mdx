---
title: Permissions
description: The access contract blocks check with can(), the role catalog and permission overrides.
---

`permissions` installs the access contract every block checks with: `can`,
`tenant_ids_with` and `is_platform`, the role tables, and the catalog of
operations from `OPERATIONS` with the default roles. The
[permissions guide](/docs/repository/permissions) explains the contract, the
catalog, overrides and how a block declares its keys.
