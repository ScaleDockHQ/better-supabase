---
title: JSON Schema checks
description: pg_jsonschema check constraints for jsonb columns that declare a schema, with errors the client maps to a validation error.
---

`jsonb-schemas` enforces the shape of a `jsonb` column in the database. A
column that declares a `schema` in `config.json` gets a pg_jsonschema check
constraint and a trigger that reports what failed, so a write that TypeScript
would reject fails in SQL too.

```bash
better-supabase add jsonb-schemas
```

## Declare a schema

```ts title="better-supabase.config.ts"
json: {
  "public.invoices.metadata": { schema: "./schemas/invoice-metadata.json" },
},
```

The generated module writes one `check_json_schema` trigger and one check
constraint per declared column. A SQL `null` passes, as it does for the check.

## Functions

| Function                                                 | Returns   | Meaning                                                             |
| -------------------------------------------------------- | --------- | ------------------------------------------------------------------- |
| `check_json_schema()`                                    | `trigger` | Runs before the check constraint and raises `23514` with the errors |
| `extensions.jsonschema_validation_errors(schema, value)` | `text[]`  | pg_jsonschema's errors for one value                                |

A failed write carries the errors as a JSON array in `DETAIL` and the hint
`JSON_SCHEMA_INVALID`; the client maps it to a `validation` error.
