---
title: Credentials
description: credential_get, credential_set and credential_revoke, the tables behind a versioned CredentialProvider.
---

`credentials` stores a reference to a secret per owner and exposes
`credential_get`, `credential_set` and `credential_revoke`, so a block never
reads a secret from its own table. The
[credentials guide](/docs/extending/credentials) covers the provider
contract, the versioning and which blocks store a `credential_ref`.
