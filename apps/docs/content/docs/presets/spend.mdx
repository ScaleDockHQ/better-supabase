The `spend` preset is for an app in the style of Ramp or Expensify. An
employee submits an expense with its receipt, the policy checks it, a manager
approves it, and the reimbursement is paid through the ledger.

## Config

```ts title="better-supabase.config.ts"
import { defineConfig } from "better-supabase/config";

export default defineConfig({ preset: "spend" });
```

`npx better-supabase init --preset spend` starts a new project from it, and
`npx better-supabase apply --preset spend` adds it to one you have
([CLI](/docs/cli/presets)).

## Blocks

The preset is [`saas`](/docs/presets#named-presets) plus these blocks, and
whatever they require:

| Block                                   | Role in the app                                             |
| --------------------------------------- | ----------------------------------------------------------- |
| [expenses](/docs/blocks/expenses)       | Expenses, receipts, policies and reimbursements             |
| [approvals](/docs/blocks/approvals)     | Manager and finance approval steps                          |
| [attachments](/docs/blocks/attachments) | Receipt images and PDFs                                     |
| [ai-files](/docs/blocks/ai-files)       | Receipt files handed to a model to read the amount and date |

The expenses block posts to the [ledger](/docs/blocks/ledger), which the
preset installs as one of its requirements.

## How the blocks connect

An expense holds its amount in minor units and its receipt as an
attachment. The policy decides whether it needs approval, and the approval
request runs its steps before the expense is reimbursed. A reimbursement is
a ledger transaction, so what the company owes each employee is a ledger
balance.

## With ReUI

- Data Grid for expenses, with Filters on status, category and amount.
- A file upload with a preview of the receipt next to the expense form.
- Badge variants for the expense status (submitted, approved, paid).
