---
title: Imports
description: CSV imports with a suggested mapping, a dry run, and `runImport`, which writes the rows in batches and marks the import failed when a batch throws.
---

`imports` is the counterpart of the data-lifecycle exporter. `parseCsv` reads RFC 4180 CSV (`SPEC_PINS.rfc4180`). `defineImport` names the kind, a Standard Schema for one row, a row key and an `insert` function. `suggestMapping` pairs headers to fields. `dryRun` validates every row and returns errors without writing. `runImport` records the run, skips keys that already imported, inserts the rest in batches of 100 and finishes with `import.completed` or `import.failed`.

```bash
better-supabase add imports
```

```ts
import { defineImport, runImport } from "better-supabase/blocks/imports";
```

The row key makes a rerun skip a row that already imported.

## Adopt mode

Map `tables.runs` onto the app's import table. Optional columns can be `null`.

## Hooks

`createImports` takes `hooks`, keyed by method name, that run your code
before and after a call: refuse it with a `DbError`, rewrite its arguments
or observe the result (see [extending blocks](/docs/extending/blocks#hooks)).
