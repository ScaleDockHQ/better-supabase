---
title: Tags
description: Tag definitions per kind, applied to subjects through one table or a link table per subject.
---

`tags` keeps definitions (`kind`, `name`, `slug`, `color`) and applies them to records. Managing definitions needs `tags.manage`. Applying a tag needs the subject's own read permission, and the tag's kind must be one the subject allows.

```bash
better-supabase sql add tags
```

```ts
import { createTags } from "better-supabase/blocks/tags";
```

In managed mode every application lives in `taggings` (`subject_type`, `subject_id`). In adopt mode each subject can name its own link table.

Tags run in every [scope](/docs/blocks/sql#scope-and-naming). In `user` scope each user has their own tags, and in `none` scope every signed-in user shares one set.

## Adopt mode

```ts title="better-supabase.config.ts"
tags: {
  mode: "adopt",
  tables: { tags: "public.organization_tags" },
  options: {
    subjects: {
      task: {
        table: "public.tasks",
        kinds: ["task"],
        links: { table: "public.task_tags", subject: "task_id", tag: "tag_id" },
      },
    },
  },
},
```

`links` columns are `subject`, `tag` and optional `tenant` and `createdAt`.

## Order

Tags of a kind are ordered by `rank`, a fractional key (see [Rank](/docs/blocks/rank)). `create` appends a tag after the last one of its kind, and `reorder(id, { previous, next })` moves it between the tags with those keys. Version 2 of the module replaced the integer `position` column with `rank`: the upgrade backfills keys in the old order and drops `position`. In adopt mode `rank` is optional; map it to `null` when the table has no such column.

## Your own columns

Add columns to the tag table with `blocks.tags.options.extraColumns`
(column name to SQL type), then pass a Standard Schema for them as `fields`.
`create` and `update` (the last argument) validates and writes them, and `create` return them parsed under
`fields`. The block also takes `hooks` around its methods; see
[extending blocks](/docs/extending/blocks).

```ts
import { createTags } from "better-supabase/blocks/tags";
import { z } from "zod";

const client = createTags({
  transport,
  fields: z.object({ priority: z.enum(["low", "high"]) }),
});
```
