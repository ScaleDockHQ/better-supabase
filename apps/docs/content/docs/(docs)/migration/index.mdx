This release upgrades from 0.53 only. An app on an older version upgrades to
0.53 first with that release, then follows the 0.53 to 0.54 guide, the 0.57
to 0.58 guide and the 0.66 to 0.67 guide. To bring
better-supabase into an app that already runs, start with the existing-apps
guide. Each change is in the
[changelog](https://github.com/ScaleDockHQ/better-supabase/blob/main/packages/better-supabase/CHANGELOG.md).

| Page                                                                  | Covers                                                                         |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| [From 0.57 to 0.58](/docs/migration/0.57-to-0.58)                     | One naming convention, declarative module files and CLI contract 3             |
| [From 0.66 to 0.67](/docs/migration/0.66-to-0.67)                     | Sessions on `@supabase/ssr`, no lite client, peer floors at the tested release |
| [Existing apps](/docs/migration/existing-apps)                        | Adopting better-supabase one module at a time next to your own tables          |
