# Support

- Bugs: open a [bug report](https://github.com/ScaleDockHQ/better-supabase/issues/new?template=bug.yml).
- New APIs, adapters or kit modules: open a [feature request](https://github.com/ScaleDockHQ/better-supabase/issues/new?template=feature.yml) before a pull request.
- Docs: open a [docs issue](https://github.com/ScaleDockHQ/better-supabase/issues/new?template=docs.yml), or send a pull request against `apps/docs/content/docs`.
- Security: follow [`SECURITY.md`](./SECURITY.md). Never open a public issue.

Maintainer conventions are in [`AGENTS.md`](./AGENTS.md). The documentation is at [bettersupabase.com/docs](https://bettersupabase.com/docs).
